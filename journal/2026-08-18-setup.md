## What happened

Built the learning framework before starting the course, on the theory that the
default way of doing this — watch lecture, nod, pattern-match the assignment,
forget it in three weeks — doesn't actually produce understanding.

Decisions made:

- **Socratic teaching with escalating hints.** Claude doesn't answer when I'm
  stuck; it escalates question → hint → analogy → partial → answer. Escape hatch
  is saying "just tell me", which gets logged and retested later.
- **Claude writes the journal, raw, in my voice.** Wrong turns kept, phrasing
  kept, nothing smoothed into good prose. The mess is the point — it's the blog
  material, and a cleaned-up entry is worth nothing.
- **~1 hour most days**, so the ritual is compressed to ~10 min of overhead:
  ~6 min `/start`, ~7 min `/wrap`, nothing else mandatory.

Then set up assignment 1: cloned the official handout, removed its inner `.git`
so my work lands in my own repo, synced deps with `uv`. `uv run pytest` gives
46 failures, all `NotImplementedError`. That's the starting line.

Found out the handout ships its own `CLAUDE.md` with essentially the same
teaching rules Stanford wrote independently — guide, don't solve. Theirs is
stricter (no Python at all from the agent), and theirs wins inside that folder.
